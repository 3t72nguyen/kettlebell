KETTLEBELL TIMER - iPhone 12 Pro Max home-screen app
=====================================================

Contents
  index.html                 the app (all code in one file)
  manifest.webmanifest       app name, colours, icons
  sw.js                      offline cache (works once hosted over HTTPS)
  icons/                     180, 192 and 512 px icons
  splash/                    1284x2778 launch screen for iPhone 12 Pro Max

Install on your iPhone
  1. Upload the whole folder to any HTTPS static host
     (Netlify Drop, GitHub Pages or Cloudflare Pages all work).
  2. Open the address in Safari on the iPhone.
  3. Tap Share, then "Add to Home Screen", then Add.
  4. Open it from the new "KB Timer" icon. It runs full screen and works offline
     after the first load.

Tips
  - Turn the silent switch off so the voice countdown is audible.
  - Tap START once so Safari allows speech.
  - REP PACE (1-10 s per rep) and GET READY (1-60 s between exercises) are the two wheels beside START.
  - The PLANK wheel sets the hold time for every plank (PLAN keeps each plank's own time).
  - Your sets, rest, plank, pace, get-ready and custom reps are saved on the phone.
